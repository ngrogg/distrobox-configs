# Distrobox Configs

## Overview
Config files and scripts for my Distrobox containers.

## Files
* **configs**, Configuration files.
  - **distrobox.conf**, Config file for per user distrobox configs.
  Goes in `~/.config/distrobox/distrobox.conf`.
* **containers**, Scripts to configure containers.
  - **dev_box.sh**, Create a Distrobox container for development purposes.
  - **google_cloud_sdk_container.sh**, Create a Distrobox container for use with the Google Cloud SDK.
